# ADR 0001：独立的 Android 应用

## 状态

已采纳

## 决定

阅读作为 `app.xvi.reader` 单独发布。数据库 `reader-local.db`、媒体目录 `reader-media`、
SecureStore 键、主题和 AI 任务都归它自己，运行时不读取其他应用的文件或数据库。首次安装从空数据开始。

## 影响

- 可以单独构建、测试和发布，OCR 和后台 AI 任务不依赖别的应用。
- 和其他应用之间没有数据同步。以后要导入数据，需要另外设计导入格式，并写新的 ADR。
- 从其他项目复制来的公共代码在本仓库里维护，不通过相对路径或 workspace 依赖引用外部源码。
