# 产品范围

阅读是一个只在 Android 上运行的读书笔记应用，数据全部存在手机本地。

## 做什么

- 书籍资料、封面、阅读状态和进度。
- 图片摘录：页码或位置、OCR 原文、可编辑的整理文本。
- AI 整理摘录、生成摘要和问题建议；AI 结果记下它基于的原文版本，原文改过后旧结果不会覆盖新内容。
- 书籍、摘录、文件夹、收藏和讨论。
- 本地 OCR；AI 服务由用户自己配置，后台 AI 任务在应用被切走后继续。
- 阅读计时和阅读记录。
- 局域网只读网页，见 [lan-reading.md](../lan-reading.md)。
- 系统分享、书籍导出、备份与恢复。

## 不做什么

- 不和其他应用共享数据库、设置或媒体文件。
- 没有账号和云同步。
- 网页不能编辑，也不能发起 AI 或 OCR。
- 没有 iOS 版，没有服务端 OCR。
- AI 拿不到 SQL 或本地数据的写权限。

## 数据位置

数据库是 `reader-local.db`，图片在 `reader-media` 目录，本地设置的键都以 `reader.` 开头，
包名是 `app.xvi.reader`。
